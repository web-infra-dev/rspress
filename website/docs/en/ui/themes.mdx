## Minimal

Inspired by the documentation layout of [Ruixen UI](https://ruixen.com/docs/components/card-carousel-hero), this preset reproduces the three-column layout, Geist typography, sidebar spacing, outline links, document headings, numbered steps, and code tabs. It includes light and dark colors and keeps Rspress's responsive navigation.

The stylesheet uses [CSS variables](/ui/vars) and built-in BEM class names. The normal custom theme entry adds the breadcrumb. CSS styles the built-in outline while preserving reading progress, edit, and back-to-top actions. It imports the stylesheet, wraps the default layout using its slots, and reexports built-in components. The website previews the same source folder.

The CSS loads Geist and Geist Mono from a pinned font CDN. You can host these fonts locally by replacing the two `@font-face` URLs.

## Rspress v1

Inspired by the [Rspress v1 documentation](https://v1.rspress.rs/guide/start/introduction), this preset brings back Open Sans typography, classic blue links, rounded sidebar highlights, and slate backgrounds in dark mode. It refines the original style with more readable navigation, balanced content spacing, and softly bordered code blocks.

It uses [CSS variables](/ui/vars) and built-in BEM class names with the Rspress v2 theme. Copy the preset folder to use the same styles in your own site. The CSS loads Open Sans from a pinned font CDN; you can replace the `@font-face` URL to host the font yourself.

</ThemePresetContent>

## Use a preset

Select a theme, then click **Copy prompt**. Paste the prompt into your AI agent in your Rspress project. It includes instructions and the official resources for applying the selected theme while preserving your existing content and customizations.

The **Rspress** prompt helps restore the default theme; the **Minimal** prompt helps apply the complete preset, including its layout components; the **Rspress v1** prompt helps apply the classic stylesheet.

## Customize the colors

Ask your agent to adjust the preset's [CSS variables](/ui/vars) for your preferred colors in both light and dark appearances. See [Custom theme](/guide/basic/custom-theme) for more customization options.

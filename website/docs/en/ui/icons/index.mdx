# Built-in icons

import { SvgWrapper, SourceCode } from '@rspress/core/theme';

When Rspress uses icons, it uses a `SvgWrapper` component to render icons. It supports icon as a URL or an svgr React component:

```ts
type Icon = React.FC<React.SVGProps<SVGSVGElement>> | string;
```

The following code is an example of how Rspress uses `IconGithub`:

```mdx preview
import { SvgWrapper, IconGithub } from '@rspress/core/theme';

<SvgWrapper icon={IconGithub} width={24} height={24} />
```

## Usage

When you want to replace Rspress built-in icons, use [Custom Theme - Re-export](/guide/basic/custom-theme#reexport) for replacement.

```tsx title="theme/index.tsx"
export { IconGithub } from './my-icons';
export * from '@rspress/core/theme-original';
```

## Brand icons

Logos for platforms, AI services, and developer tools.

```tsx preview
import {
  SvgWrapper,
  IconGithub,
  IconGitlab,
  IconAnthropic,
  IconOpenAI,
  IconNpm,
  IconYarn,
  IconPnpm,
  IconBun,
  IconDeno,
} from '@rspress/core/theme';

export default () => {
  return (
    <div style={{ display: 'flex', gap: 8, flexWrap: 'wrap', fontSize: 12 }}>
      {[
        IconGithub,
        IconGitlab,
        IconAnthropic,
        IconOpenAI,
        IconNpm,
        IconYarn,
        IconPnpm,
        IconBun,
        IconDeno,
      ].map((Icon, idx) => (
        <SvgWrapper icon={Icon} key={idx} width={24} height={24} />
      ))}
    </div>
  );
};
```

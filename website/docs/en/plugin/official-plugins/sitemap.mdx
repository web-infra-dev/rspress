# @rspress/plugin-sitemap (Legacy) <SourceCode href="https://github.com/web-infra-dev/rspress/tree/main/packages/plugin-sitemap" />

import { SourceCode } from '@rspress/core/theme';

:::warning Legacy plugin

Sitemap generation is built into Rspress and enabled by default. Use the [`sitemap`](/api/config/config-basic#sitemap) configuration instead of installing this plugin.

:::

## Migration

Remove the `pluginSitemap` import and its entry in `plugins`. If you passed options to `pluginSitemap`, move them to `sitemap`:

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  siteOrigin: 'https://example.com',
  sitemap: {
    defaultChangeFreq: 'weekly',
    defaultPriority: '0.7',
  },
});
```

If you used `pluginSitemap()` without options, remove it and keep [`siteOrigin`](/api/config/config-basic#siteorigin) configured to generate absolute URLs. If you used `siteUrl`, you can retain it as `sitemap.siteUrl`.

Existing plugin usage remains supported with a legacy warning. Explicit `sitemap` options take precedence over plugin options, and `sitemap: false` disables generation even when the plugin is present.

See [`sitemap`](/api/config/config-basic#sitemap) for all options and defaults.

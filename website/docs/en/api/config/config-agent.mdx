# AI config

These options configure Markdown generation and browser agent tools. `llms` and `webMcp` are top-level options in `rspress.config.ts`.

## llms

- **Type**:

```ts
boolean | {
  llmsTxt?: (context: LlmsTxtContext) => string | Promise<string>;
  remarkSplitMdxOptions?: RemarkSplitMdxOptions;
}
```

- **Default**: `false`

Whether to enable [SSG-MD](/guide/basic/ssg-md) to generate `llms.txt`, `llms-full.txt`, and Markdown files for each page, making your documentation easier for large language models to understand.

Enabling `llms` also enables the Markdown copy and AI tool UI by default. Use [`themeConfig.llmsUI`](/api/config/config-theme#llmsui) to customize or disable these controls.

Use `llmsTxt` to compose the complete `llms.txt` content from site metadata and page sections. See [Customize llms.txt](/guide/basic/ssg-md#customize-llmstxt) for details.

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  llms: true,
});
```

:::warning

`llms` is an experimental feature. If SSG-MD cannot be enabled due to SSR incompatibility, use [@rspress/plugin-llms](/plugin/official-plugins/llms) as a fallback.

:::

For detailed usage, configuration options, and implementation principles, see [llms.txt (SSG-MD)](/guide/basic/ssg-md).

## webMcp

- **Type**: `boolean | { exposedTo?: string[] }`
- **Default**: `true`

Expose built-in documentation tools through the browser's native WebMCP API. Set `webMcp: false` to disable them. Browsers without WebMCP support continue to render the site normally.

Tool availability follows the owning components. Page-reading tools are registered by `LlmsHint` and require Markdown generated by a production build with [`llms`](#llms) enabled. Local search registers its tool through the default search panel; Algolia integration is not supported yet.

Use `exposedTo` to allow specific secure origins to discover the tools:

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  llms: true,
  webMcp: {
    exposedTo: ['https://agent.example'],
  },
});
```

See [WebMCP](/guide/basic/webmcp) for available tools, browser requirements, and cross-origin access.

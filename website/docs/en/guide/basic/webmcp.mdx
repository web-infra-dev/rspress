# WebMCP

<VersionBadge version="2.1.0" />

Rspress enables [`webMcp`](/api/config/config-agent#webmcp) by default, so agents can use [WebMCP](https://developer.chrome.com/docs/ai/webmcp) to search, read, and navigate Rspress documentation. For more details, see [ChatGPT - Site tools](https://learn.chatgpt.com/docs/webmcp).

<Prompt
  title="Try WebMCP with your agent"
  description="Send this prompt to Codex or another agent to see which WebMCP tools the page offers."
  prompt="Open https://rspress.rs in the browser and list the WebMCP tools the page exposes. Give the name and purpose of each tool."
/>

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  webMcp: true, // default value
});
```

Set `webMcp: false` to disable the Rspress built-in tools. The [`useWebMcp`](/ui/hooks/use-web-mcp) hook remains available for registering custom tools.

See [AI config](/api/config/config-agent#webmcp) for the configuration reference.

## Built-in tools

| Tool                       | Purpose                                                                                                                          |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `rspress_get_site_info`    | Site metadata, locales, versions, navigation, and the active sidebar.                                                            |
| `rspress_list_pages`       | Filter and paginate page metadata, defaulting to the active language and version. Works independently of search.                 |
| `rspress_get_page`         | Read metadata, frontmatter, TOC, and Markdown for a known route without navigating (enabled with [SSG-MD](/guide/basic/ssg-md)). |
| `rspress_get_current_page` | Read metadata, frontmatter, TOC, and Markdown for the current page (enabled with [SSG-MD](/guide/basic/ssg-md)).                 |
| `rspress_search_docs`      | Search the local documentation index for the active language and version (default theme local search only).                      |
| `rspress_navigate`         | Navigate to a known internal route, then return committed page metadata, section routes, and previous/next pages.                |

Route paths exclude the configured `base` and support query strings and hashes.

`rspress_list_pages` accepts `query`, `lang`, `version`, `limit` (1–100, default 50), and `offset` (default 0). Its query matches page titles, descriptions, routes, and headings. `rspress_search_docs` accepts `query` and `limit` (1–20, default 10).

## Cross-origin agents

Use [`webMcp.exposedTo`](/api/config/config-agent#webmcp) to allow specific secure origins to discover tools.

## Custom tools

Use [`useWebMcp`](/ui/hooks/use-web-mcp) from `@rspress/core/runtime` to register tools in your own components. Tools are automatically removed when the component unmounts.

# WebMCP

<VersionBadge version="2.1.0" />

Rspress enables [`webMcp`](/api/config/config-agent#webmcp) by default, so agents can use [WebMCP](https://developer.chrome.com/docs/ai/webmcp) to search, read, and navigate Rspress documentation. For more details, see [ChatGPT - Site tools](https://learn.chatgpt.com/docs/webmcp).

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  webMcp: true, // default value
});
```

Set `webMcp: false` to disable the Rspress built-in tools. The [`useWebMcp`](/ui/hooks/use-web-mcp) hook remains available for registering custom tools.

## Built-in tools

| Tool               | Purpose                                                                                                                          |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| `get_site_info`    | Site metadata, locales, versions, navigation, and the active sidebar.                                                            |
| `list_pages`       | Filter and paginate page metadata, defaulting to the active language and version. Works independently of search.                 |
| `get_page`         | Read metadata, frontmatter, TOC, and Markdown for a known route without navigating (enabled with [SSG-MD](/guide/basic/ssg-md)). |
| `get_current_page` | Read metadata, frontmatter, TOC, and Markdown for the current page (enabled with [SSG-MD](/guide/basic/ssg-md)).                 |
| `search_docs`      | Search the local documentation index for the active language and version (default theme local search only).                      |
| `navigate`         | Navigate to a known internal route, then return committed page metadata, section routes, and previous/next pages.                |

## Cross-origin agents

Use [`webMcp.exposedTo`](/api/config/config-agent#webmcp) to allow specific secure origins to discover tools.

## Custom tools

Use [`useWebMcp`](/ui/hooks/use-web-mcp) from `@rspress/core/runtime` to register tools in your own components. Tools are automatically removed when the component unmounts.

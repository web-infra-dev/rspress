# Internationalization

To internationalize a Rspress documentation site, complete the following steps:

1. Configure the language list and default language in `rspress.config.ts`.
1. Create docs and navigation files for each language.

Optionally, define shared translations in `i18n.json` and use the `useI18n` hook to read them in custom components.

## Configure `rspress.config.ts`

Edit `rspress.config.ts` to configure:

- [`locales`](/api/config/config-basic#locales): The supported languages and site-level information for each language, such as `title` and `description`.
- [`lang`](/api/config/config-basic#lang): The default site language. Its value should match a `lang` entry in `locales`.

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  lang: 'en',
  locales: [
    {
      lang: 'en',
      // The label in the navbar language switcher
      label: 'English',
      title: 'Rspress',
      description: 'Static Site Generator',
    },
    {
      lang: 'zh',
      label: '简体中文',
      title: 'Rspress',
      description: '静态网站生成器',
    },
  ],
});
```

**Rspress removes the language prefix from routes in the default language**. With `lang: 'en'`, `/en/guide/start/introduction` becomes `/guide/start/introduction`, while the Chinese route keeps its prefix: `/zh/guide/start/introduction`.

:::tip Note

`themeConfig.locales` also contains all fields from `locales`, but it will be removed in the future. Use `locales` instead.

:::

For other internationalized theme options, see [API type](/api/config/config-theme#locales).

## Create docs for each language

Create a directory for each language under your docs root. The directory names should match the `lang` values in `locales`:

```tree
├── docs
│   ├── en
│   │   ├── _nav.json
│   │   ├── api
│   │   │   └── index.mdx
│   │   ├── guide
│   │   │   ├── _meta.json
│   │   │   └── start
│   │   │       ├── introduction.mdx
│   │   │       └── quick-start.mdx
│   │   └── index.md
│   └── zh
│       ├── _nav.json
│       ├── api
│       │   └── index.mdx
│       ├── guide
│       │   ├── _meta.json
│       │   └── start
│       │       ├── introduction.mdx
│       │       └── quick-start.mdx
│       └── index.md
├── package.json
├── rspress.config.ts
└── tsconfig.json
```

Here, docs for different languages live in the `en` and `zh` directories under `docs`, making each language version easy to distinguish.

Within each language directory, use `_nav.json` and `_meta.json` to configure the navbar and sidebar. For details, see [Autogenerated navigation](/guide/basic/auto-nav-sidebar).

### Navigation bar \_nav.json

In each language's `_nav.json`, write `text` in that language. For example, the English navbar is:

```json title="docs/en/_nav.json"
[
  {
    "text": "Guide",
    "link": "/guide/start/introduction"
  },
  {
    "text": "API",
    "link": "/api/"
  }
]
```

In `docs/zh/_nav.json`, use Chinese text such as `指南` for the same navigation item.

### Sidebar \_meta.json

Similarly, write sidebar labels in the corresponding language:

```json title="docs/en/guide/_meta.json"
[
  {
    "type": "dir",
    "name": "start",
    "label": "Getting Started"
  }
]
```

In `docs/zh/guide/_meta.json`, use `开始` as the label. These language-specific navigation files do not require `i18n.json`.

## Use `i18n.json` (optional)

The setup above is enough for a multilingual documentation site. If you want to manage translations in one place and reuse them in navigation or custom components, you can optionally add an `i18n.json` file.

### Define I18n text data

Create `i18n.json` next to `rspress.config.ts`:

```tree
.
├── docs
├── i18n.json
├── package.json
├── tsconfig.json
└── rspress.config.ts
```

Define the text required for internationalization in this JSON file. Its type is:

```ts
export interface I18n {
  // key: text id
  [key: string]: {
    // key: language
    [key: string]: string;
  };
}
```

For example:

```json title="i18n.json"
{
  "gettingStarted": {
    "en": "Getting Started",
    "zh": "开始"
  },
  "api": {
    "en": "API",
    "zh": "API"
  },
  "guide": {
    "en": "Guide",
    "zh": "指南"
  }
}
```

### Use translations in navigation

With `i18n.json` defined, you can use the same translation keys in each language's navigation files. Rspress resolves them using the current language.

In `_nav.json`, use translation keys for `text`:

```json title="_nav.json"
[
  {
    "text": "guide",
    "link": "/guide/start/introduction"
  },
  {
    "text": "api",
    "link": "/api/"
  }
]
```

In `_meta.json`, use translation keys for `label`:

```json title="_meta.json"
[
  {
    "type": "dir",
    "name": "start",
    "label": "gettingStarted"
  }
]
```

For example, `guide` becomes `Guide` in English and `指南` in Chinese, while `gettingStarted` becomes `Getting Started` or `开始`.

### Use `useI18n` in custom components (optional)

If your MDX components or [custom theme](/guide/basic/custom-theme) also need these translations, use the `useI18n` hook to read them from `i18n.json`.

import UseI18n from '../../fragments/useI18n.mdx';

<UseI18n />

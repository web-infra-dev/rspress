# 国际化

在 Rspress 中实现文档的国际化，需要完成以下步骤：

1. 在 `rspress.config.ts` 中配置语言列表和默认语言。
1. 新建各语言的文档和导航配置文件。

你还可以按需在 `i18n.json` 中定义共享的翻译文本，并在自定义组件中通过 `useI18n` hook 获取这些文本。

## 配置 `rspress.config.ts`

编辑 `rspress.config.ts`，配置以下选项：

- [`locales`](/api/config/config-basic#locales)：站点支持的语言，以及各语言的标题、描述等站点信息。
- [`lang`](/api/config/config-basic#lang)：站点的默认语言，其值应与 `locales` 中某一项的 `lang` 一致。

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  lang: 'en',
  locales: [
    {
      lang: 'en',
      // 导航栏切换语言的标签
      label: 'English',
      title: 'Rspress',
      description: 'Static Site Generator',
    },
    {
      lang: 'zh',
      label: '简体中文',
      title: 'Rspress',
      description: '静态网站生成器',
    },
  ],
});
```

**对于默认语言下的路由，Rspress 会去掉语言前缀**。当 `lang` 为 `'en'` 时，`/en/guide/start/introduction` 会变为 `/guide/start/introduction`，而中文路由会保留前缀：`/zh/guide/start/introduction`。

:::tip 注意

`themeConfig.locales` 也包含 `locales` 中的所有字段。不过它将在未来被移除，请尽可能使用 `locales`。

:::

对于其它的国际化主题参数配置，请参考 [API 类型](/api/config/config-theme#locales)。

## 新建不同语言版本的文档

在文档根目录下，为每种语言创建一个目录。目录名应与 `locales` 中的 `lang` 值一致：

```tree
├── docs
│   ├── en
│   │   ├── _nav.json
│   │   ├── api
│   │   │   └── index.mdx
│   │   ├── guide
│   │   │   ├── _meta.json
│   │   │   └── start
│   │   │       ├── introduction.mdx
│   │   │       └── quick-start.mdx
│   │   └── index.md
│   └── zh
│       ├── _nav.json
│       ├── api
│       │   └── index.mdx
│       ├── guide
│       │   ├── _meta.json
│       │   └── start
│       │       ├── introduction.mdx
│       │       └── quick-start.mdx
│       └── index.md
├── package.json
├── rspress.config.ts
└── tsconfig.json
```

不同语言的文档分别存放在 `docs` 下的 `en` 和 `zh` 目录中。

在各语言目录中，通过 `_nav.json` 和 `_meta.json` 分别配置导航栏和侧边栏，具体可以参考[自动化导航栏/侧边栏](/guide/basic/auto-nav-sidebar)。

### 导航栏 \_nav.json

在各语言的 `_nav.json` 中，直接使用对应语言的 `text`。例如，英文导航栏配置为：

```json title="docs/en/_nav.json"
[
  {
    "text": "Guide",
    "link": "/guide/start/introduction"
  },
  {
    "text": "API",
    "link": "/api/"
  }
]
```

在 `docs/zh/_nav.json` 中，为同一个导航项使用中文文本，例如 `指南`。

### 侧边栏 \_meta.json

同样，在侧边栏配置中直接使用对应语言的标签：

```json title="docs/en/guide/_meta.json"
[
  {
    "type": "dir",
    "name": "start",
    "label": "Getting Started"
  }
]
```

在 `docs/zh/guide/_meta.json` 中，将标签设为 `开始`。这些按语言编写的导航配置不需要 `i18n.json`。

## 使用 `i18n.json`（可选）

完成上述配置后，多语言文档站点即可使用。如果希望集中管理翻译文本，并在导航配置或自定义组件中复用，可以按需添加 `i18n.json`。

### 定义 I18n 文本数据

在 `rspress.config.ts` 同级目录下创建 `i18n.json`：

```tree
.
├── docs
├── i18n.json
├── package.json
├── tsconfig.json
└── rspress.config.ts
```

在这个 JSON 文件中，你可以定义国际化所需的文本，类型定义如下：

```ts
export interface I18n {
  // key 为文本 id
  [key: string]: {
    // key 为语言
    [key: string]: string;
  };
}
```

例如：

```json title="i18n.json"
{
  "gettingStarted": {
    "en": "Getting Started",
    "zh": "开始"
  },
  "api": {
    "en": "API",
    "zh": "API"
  },
  "guide": {
    "en": "Guide",
    "zh": "指南"
  }
}
```

### 在导航配置中使用翻译文本

定义 `i18n.json` 后，可以在各语言的导航配置文件中使用相同的翻译 key，Rspress 会根据当前语言解析这些 key。

在 `_nav.json` 中，将 `text` 设为翻译 key：

```json title="_nav.json"
[
  {
    "text": "guide",
    "link": "/guide/start/introduction"
  },
  {
    "text": "api",
    "link": "/api/"
  }
]
```

在 `_meta.json` 中，将 `label` 设为翻译 key：

```json title="_meta.json"
[
  {
    "type": "dir",
    "name": "start",
    "label": "gettingStarted"
  }
]
```

例如，`guide` 在英文中显示为 `Guide`，在中文中显示为 `指南`；`gettingStarted` 则分别显示为 `Getting Started` 和 `开始`。

### 自定义组件中使用 `useI18n`（可选）

如果 MDX 组件或[自定义主题](/guide/basic/custom-theme)也需要这些翻译文本，可以通过 `useI18n` hook 从 `i18n.json` 中获取。

import UseI18n from '../../fragments/useI18n.mdx';

<UseI18n />

## 修改 i18n 文案 \{#customize-i18n-text}

Rspress 默认主题内置了中文（`zh`）、英文（`en`）、日文（`ja`）、韩文（`ko`）和俄文（`ru`）的界面文案。缺少对应语言的翻译时，会回退到英文。

你可以在 `rspress.config.ts` 中通过 [`i18nSource`](/api/config/config-basic#i18nsource) 覆盖已有文案，也可以为尚未内置的语言补充翻译。例如，修改编辑链接的文案：

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  i18nSource: {
    editLinkText: {
      en: 'Edit this page on GitLab',
      zh: '在 GitLab 上编辑此页',
    },
  },
});
```

修改界面文案是可选的，也适用于单语言站点。

如果已经使用了 `i18n.json`，也可以直接在该文件中添加以下条目，覆盖相同的内置文案：

```json title="i18n.json"
{
  "editLinkText": {
    "en": "Edit this page on GitLab",
    "zh": "在 GitLab 上编辑此页"
  }
}
```

要补充其他语言，在 `i18nSource` 或 `i18n.json` 的各个文案 key 下添加对应的语言代码和翻译文本即可，语言代码应与站点配置一致。尚未翻译的内置文案会继续回退到英文。

对象形式的 `i18nSource` 会与已有翻译合并，并覆盖 `i18n.json` 和 Rspress 内置文案中的同名条目。它也可以添加自定义翻译 key，供 `useI18n` 使用。

内置文案 key 和 `i18nSource` 的函数用法请参考 [API 文档](/api/config/config-basic#i18nsource)。如果希望将翻译文件放在其他位置，可以配置 [`i18nSourcePath`](/api/config/config-basic#i18nsourcepath)。

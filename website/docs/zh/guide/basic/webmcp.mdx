# WebMCP

Rspress 可以通过浏览器原生 [WebMCP API](https://developer.chrome.com/docs/ai/webmcp/imperative-api) 向浏览器智能体提供文档工具。该功能内置于 core，默认开启。启用 Markdown 生成后即可使用全部六个工具：

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  llms: true,
});
```

设置 `webMcp: false` 可以关闭内置工具。

WebMCP 是实验性功能，需要浏览器在 HTTPS 或 localhost 等安全上下文中启用 `document.modelContext`。不支持的浏览器仍可正常访问站点。Rspress 不会安装浏览器 polyfill 或 MCP 服务器。

## 内置工具

| 工具                       | 用途                                                                    |
| -------------------------- | ----------------------------------------------------------------------- |
| `rspress_get_site_info`    | 返回站点元信息、语言、版本、导航和当前侧边栏。                          |
| `rspress_list_pages`       | 筛选和分页读取页面元信息，默认使用当前语言和版本，不依赖搜索。          |
| `rspress_get_page`         | 无需跳转即可读取已知路由的元信息、frontmatter、目录和 SSG-MD Markdown。 |
| `rspress_get_current_page` | 读取当前页面的元信息、frontmatter、目录和 SSG-MD Markdown。             |
| `rspress_search_docs`      | 搜索当前语言和版本的本地文档索引。                                      |
| `rspress_navigate`         | 跳转到已知站内路由，等待页面提交后返回元信息、章节路由和前后页。        |

路径采用不含配置项 `base` 的站内绝对路径。站点部署在 `/docs/` 时，传入 `/guide` 即可跳转到 `/docs/guide`。导航保留查询参数和锚点，拒绝未知路由和外部路由。导航被其他路由覆盖或被页面错误中断时会报错，不会返回过期的页面信息。取消工具调用会停止等待结果，不会撤销已经开始的导航。

`rspress_list_pages` 接受 `query`、`lang`、`version`、`limit`（1–100，默认 50）和 `offset`（默认 0）。其中 `query` 匹配页面标题、描述、路由和章节标题。`rspress_search_docs` 接受 `query` 和 `limit`（1–20，默认 10）。

## Markdown 和搜索可用性

两个页面读取工具需要在生产构建中开启 `llms: true`，通过 [SSG-MD](/guide/basic/ssg-md) 生成页面 Markdown。运行 `rspress build` 和 `rspress preview` 后可以体验全部六个工具。未开启 `llms: true` 或使用开发服务器时，不生成 SSG-MD 产物，因此不注册 `rspress_get_page` 和 `rspress_get_current_page`。

页面读取工具由声明 Markdown 入口的 `LlmsHint` 组件注册。卸载该组件、关闭 `themeConfig.llmsUI`，或设置 `themeConfig.llmsUI.injectLlmsHint: false` 都会移除这两个工具。

搜索工具与默认搜索面板共用搜索实例及配置的 `beforeSearch`、`onSearch`、`afterSearch` hooks，在打开面板或智能体首次搜索时初始化索引。关闭弹窗不会移除工具；卸载或替换默认搜索面板会移除工具。自定义搜索组件可以通过 `useWebMcp` 注册自己的工具。切换语言或版本后会使用对应索引；设置 `search.versioned: false` 时跨版本搜索。关闭本地搜索或当前分组没有索引时，不注册搜索工具。暂不支持 Algolia 集成：使用 `@rspress/plugin-algolia` 的站点保留现有 DocSearch 界面，但不会提供 WebMCP 搜索工具。页面列表和读取工具仍可使用。

WebMCP 复用现有开发环境的页面数据和搜索索引生命周期，不会在文件编辑时额外触发全站重算；元信息和索引更新仍受现有 HMR 行为限制。

## 试用工具

在支持的浏览器中，使用对象参数调用发现的工具：

```js
const tools = await document.modelContext.getTools();
const tool = tools.find(tool => tool.name === 'rspress_get_page');
const result = await document.modelContext.executeTool(tool, {
  routePath: '/guide',
});
console.log(result);
```

## 跨源智能体

同源和浏览器内置智能体无需额外配置。若要向指定安全来源开放内置工具：

```ts
export default defineConfig({
  llms: true,
  webMcp: {
    exposedTo: ['https://agent.example'],
  },
});
```

浏览器还会应用 WebMCP 权限策略和工具发现规则，详见[跨源 API 文档](https://developer.chrome.com/docs/ai/webmcp/imperative-api#cross-origin-iframes)。

## 自定义工具

通过 `@rspress/core/runtime` 导出的 [`useWebMcp`](/ui/hooks/use-web-mcp)，可以在自定义组件中注册工具。内置工具也通过同一个 hook，直接在 `App`、`LlmsHint` 和搜索面板中注册。工具可用性跟随所属组件，`webMcp` 不提供独立的搜索或 Markdown 开关。

:::warning Legacy 插件

sitemap 生成功能已内置于 Rspress，且默认开启。请使用 [`sitemap`](/zh/api/config/config-basic#sitemap) 配置，无需安装此插件。

:::

## 迁移

移除 `pluginSitemap` 的导入和 `plugins` 中的调用。如果曾向 `pluginSitemap` 传入选项，将其移至 `sitemap`：

```ts title="rspress.config.ts"
import { defineConfig } from '@rspress/core';

export default defineConfig({
  siteOrigin: 'https://example.com',
  sitemap: {
    defaultChangeFreq: 'weekly',
    defaultPriority: '0.7',
  },
});
```

如果原来使用不带选项的 `pluginSitemap()`，直接移除即可，并保留 [`siteOrigin`](/zh/api/config/config-basic#siteorigin) 配置以生成绝对 URL。如果原来使用了 `siteUrl`，可将其保留为 `sitemap.siteUrl`。

已有的插件用法仍然受支持，但会输出 legacy 提示。显式设置的 `sitemap` 选项优先于插件选项；即使仍在使用插件，`sitemap: false` 也会关闭生成。

完整选项和默认值请参阅 [`sitemap`](/zh/api/config/config-basic#sitemap)。

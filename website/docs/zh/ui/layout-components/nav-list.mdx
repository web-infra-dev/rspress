# NavList

`NavList` 会根据所在导航区域的展示方式渲染自定义导航项。将它与 [`Layout`](/ui/layout-components/layout) 的导航插槽结合使用时，同一组导航项可以同时适配桌面端和移动端。

## 使用方式

将 `NavList` 与 `Layout` 提供的导航项插槽结合使用：

```tsx title="theme/index.tsx"
import { Layout as BasicLayout, NavList } from '@rspress/core/theme-original';

const customItems = [
  { text: '社区', link: '/community' },
  {
    text: '资源',
    items: [
      { text: '博客', link: '/blog' },
      { text: 'GitHub', link: 'https://github.com' },
    ],
  },
];

export function Layout() {
  return <BasicLayout afterRightNavItems={<NavList items={customItems} />} />;
}

export * from '@rspress/core/theme-original';
```

导航插槽在桌面端和移动端会显示在相同的位置。关于可用插槽，请参阅 [Layout](/ui/layout-components/layout#自定义导航列表) 文档。

## Props

### items

- **类型：** `NavItem[]`

要渲染的导航项。导航项结构与 [`themeConfig.nav`](/api/config/config-theme#nav) 相同，支持链接、嵌套项、图标、标签和 active 匹配等配置。
